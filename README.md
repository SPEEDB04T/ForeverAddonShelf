# Forever Addon Shelf

Installer and download page for a small set of WoW Forever addons.

## Install (Windows)

Download [Install-ForeverAddons.bat](https://github.com/SPEEDB04T/ForeverAddonShelf/releases/latest/download/Install-ForeverAddons.bat) and double-click it. It finds your WoW Forever folder (or asks for it once), shows the addons with what's new, and installs or updates the ones you tick. Run it again any time to update; it can put a shortcut on your desktop for that.

Your browser or Windows may warn about a downloaded script: choose Keep, then More info > Run anyway. The script is plain text, so you can open it in Notepad to read it first.

## Install (Linux)

```bash
bash <(curl -fsSL https://github.com/SPEEDB04T/ForeverAddonShelf/releases/latest/download/install-forever-addons.sh)
```

It looks for WoW Forever in the usual Wine, Lutris, Bottles, Heroic and Steam places (or asks once), then shows the same checklist in a zenity or kdialog window, or in the terminal. Needs `curl` and `unzip`. Options, after the closing bracket: `--text` (terminal only), `--select all` or `--select Name,Name` (no questions), and your World of Warcraft folder if it isn't found.

## Maintaining

- `addons.config.json`: the addons on the shelf (source folder and GitHub repo). To add one, add it here, give its repo a release tagged `v<version>` with `<Name>-<version>.zip` attached, run `build.ps1`, and push.
- `shelf.tsv`: the list the installers download each time they run. Generated by `build.ps1`; once it is pushed to `main`, installers already on people's machines show the new addon. No new installer release is needed for a new addon or a new version.
- `build.ps1`: writes `shelf.tsv`, `site/addons.json`, the publish file map, and the two installers in `dist/` from `installer.template.bat` and `installer.template.sh`.
- `site/index.html`: the shelf page.
- A new installer release is only needed when the installer templates themselves change: attach `dist/Install-ForeverAddons.bat` and `dist/install-forever-addons.sh` to a new release.

Testing the Windows installer without anything appearing on screen: set `FOREVER_WOW` to a test folder and `FOREVER_SNAPSHOT` to an empty folder. The window runs off-screen, installs everything, and saves pictures of itself and its timings there. `FOREVER_SELECT=all` runs it in the console instead.
